# v0.34.0 — Codex Through the Canonical Plugin

**Date:** 2026-10-17

## Highlights

- **Codex installs Mirror as a plugin, from a marketplace the package ships**
  (CV21.DS4.US1). Two commands — `codex plugin marketplace add "<pkg>"`, then
  `codex plugin add mirror-mind@mirror-mind` — and Codex asks once, at the
  next session, to trust the plugin's hooks. `mirror init` prints exactly
  these steps when it finds `codex` on the PATH.
- **Codex is at L4, measured live** (CV21.DS4.US4, on Codex 0.163.0): all 25
  skills, the Operating Instructions as a developer message, Mirror Mode on
  an ordinary turn and on `$mirror-mind:mm:mirror`, the 7 MCP tools behind
  Codex's `tool_search`, and every prompt and reply logged as `codex`. Codex
  detaches the TUI on `/quit` and fires SessionEnd only when its daemon reaps
  the idle thread, so Mirror gained a safety net for sessions that outlive
  their TUI: session maintenance closes them as orphans
  (`MIRROR_STALE_ORPHAN_MINUTES`, default 30).
- **A bounded SessionEnd no longer cuts extraction** (CV21.DS4.TS2). Codex
  bounds the hook at 1 s; the close now runs no LLM work, and the next
  session start finishes the deferred tail. Grok's 1.5 s bound rides the same
  change.
- **`$`-skill turns are command turns** (CV21.DS4.TS3), as `/`-commands are
  on every other runtime, with Mirror's explicit form the one exception.
- **The v0.32.1 Codex wiring is removed** (CV21.DS4.TS5). What no longer
  exists: `scripts/codex-mirror.sh`, `scripts/codex-hooks/`, the
  `codex:session-*` hook entries, and
  `conversation-logger backfill-codex-session` — the plugin logs Codex turns
  as they happen, so nothing re-imports the transcript at exit. A
  retired-surfaces guard keeps the wiring from drifting back.
- **An updated Mirror now reaches Codex's plugin cache — or says so**
  (CV21.DS4.TS6). Codex copies the plugin into its cache at a version, so an
  npm update changes the install but not the copy Codex runs. `runtime
  diagnose` reports `codex_plugin_cache_behind` naming both versions and the
  measured command — `codex plugin add mirror-mind@mirror-mind`; re-adding
  refreshes the cache in place, no remove needed — and a successful `runtime
  update` prints the same line. A dangling Claude Code skills link is
  reported too (`claude_plugin_link_dangling`). Absence is not drift: an
  unwired machine stays green.

## Where We Started

v0.33.0 proved one plugin works as it is on Claude Code, Codex, and Grok.
But a Codex user still wired Mirror by hand: a skills link, an `AGENTS.md`
link, and a wrapper script around every session that imported the transcript
from JSONL at exit — v0.32.1's wiring, built when Codex had no hook system.
Codex 0.157 added plugins; DS4 asked whether the canonical plugin could be
the whole answer, and set a gate: the old wiring retires only once parity is
shown live.

## What Changed

**The install is two commands.** The npm package root carries
`.agents/plugins/marketplace.json`, one local plugin — the same
`plugins/mirror-mind` Claude Code loads. Codex copies it into its cache at
the plugin's version and runs its Claude-family hooks as they are; runtime
detection reads Codex's `turn_id` and labels the session `codex`.

**The gate was met, so the old path is gone.** US4 measured L4 twice, live,
through the shipped plugin alone. TS5 then removed the wrapper, its generated
hooks, the `codex:*` hook family, the JSONL backfill (its only caller was the
wrapper's exit hook; the plugin's SessionEnd closes without reading it),
their pack-contents guards, and their CI step. The docs name the marketplace
install and nothing else.

**The one stale copy is watched.** Claude Code reads the plugin through a
link, in place; Codex runs a versioned copy. TS6 taught `runtime diagnose`
and `runtime update`'s post-update hints to compare that copy against the
installed version — the landed version, read from the just-updated tree —
and to print the one command that works on Codex 0.163.0, which has no
plugin-update verb: the re-add.

## Upgrading

```bash
npm install -g mirror-mind@latest    # or: mirror runtime update
```

**If Codex runs the plugin already:** after this update (and any future one),
bring the cache level once:

```bash
codex plugin add mirror-mind@mirror-mind
```

`mirror runtime diagnose` will tell you whenever this is needed.

**If you wired Codex before the plugin** (a skills link, an `AGENTS.md` link,
the wrapper script): install the plugin with the two commands above, then
undo the old wiring — the exact steps are in Getting Started's Codex section.
If you do nothing, everything still works, at the cost of doubled skills and
double logging where the old wrapper still runs; an older installed package
keeps its own wrapper copy, but this version ships none.

No migration. Existing homes, sessions, and memories are untouched.

## Conscious Exclusions

- **Codex logging is no longer end-to-end tested**, by decision: the retired
  wrapper smoke was the only artifact-level Codex check. Confidence now rests
  on the shared Claude-family hook path (smoked), runtime-detection units,
  and US4's live measurement.
- **Mirror never runs `codex` itself.** The cache readers are read-only
  filesystem checks; the person runs the printed command.
- **Two named silences in the wiring checks:** a cache *ahead* of the install
  (a deliberate downgrade gets no advice from the older tree), and a Claude
  link that resolves to another install tree (healthy means the target
  reads). Both are recorded as decisions with tests.
- **CR142 is captured, not fixed:** the Claude plugin smoke's negative probe
  fails on a machine with a globally installed `mirror-hook` — a smoke
  isolation bug found during TS5's validation, pre-existing, filed under
  RS010.

## What We Learned

The gate ordering did the work: retiring the old wiring only after L4 was
measured live meant the removal was a deletion, not a bet. And the one real
surprise of the arc — Codex sessions outlive their TUI — was caught by the
live measurement, not by any test, which is why the measurement is part of
the method.

## Next Horizon
