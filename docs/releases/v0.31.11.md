# v0.31.11 — Confined Operational Relative Links

**Date:** 2026-08-26

## Highlights

- Accepts one-level and multi-level parent-relative Ariad roadmap links when the
  canonical target remains inside the registered Journey.
- Preserves normalized Journey-relative projection paths and confined directory
  links resolving to `index.md`.
- Continues rejecting canonical escapes, absolute paths, URI-like targets,
  backslash-based paths, and directory or file symlinks escaping the Journey.
- Preserves the previous valid Operational document and manifest when a confined
  target is missing or compilation otherwise fails before publication.
- Adds an isolated public-CLI regression matching the Nautilus capability package
  linking to a root-level Delivery Story.

## Where We Started

Nautilus adopted `mirror.journey-projections@1.0` from v0.31.10 and immediately
exercised a legitimate roadmap topology the normative synthetic fixture did not
contain: a capability package linked back to a root-level Delivery Story through
`../ds-001/index.md`. Mirror rejected the lexical `..` segment before asking
whether the resolved file remained inside the registered Journey.

The source Ariad mutation still committed and the projection kernel correctly
preserved the previous valid pair. That safety posture prevented corruption, but
left the Operational snapshot stale and blocked Tactical and Strategic consumers
from claiming ancestry from current truth.

## What Changed

`OperationalCompiler` now resolves a relative source target from the containing
document before classifying its safety. Canonical Journey-root confinement, not
the mere presence of a parent segment, is the authority. Existing target and
symlink components are canonicalized; a result outside the registered root still
returns the structured `unsafe_projection_path` error without leaking a host
path.

A missing target whose unresolved canonical location remains inside the Journey
continues to return a bounded source-compilation failure. Directory targets still
resolve only to a confined `index.md`. Publication remains exclusively owned by
the existing per-Journey linearizable kernel, so compiler failure cannot replace
the last valid projection or manifest.

The regression matrix covers same-directory links, one and multiple confined
parent segments, confined directories, canonical escape, absolute path, file URI,
Windows separator, file and directory symlink escape, missing target, and
last-valid preservation. A guarded isolated public rebuild reproduces the exact
CV-to-root-DS shape that exposed the defect.

## Conscious Exclusions

- No Nautilus-specific semantics enter Mirror Core.
- No Tactical or Strategic schema or synthesis behavior changes.
- No roadmap links are rewritten as a workaround.
- No projection namespace, atomicity, receipt, or publication rule changes.
- No TypeScript parity work while CV22 remains paused.

## What We Learned

Lexical traversal and boundary escape are not equivalent. Rejecting every `..`
looks conservative, but it substitutes syntax for authority and can make valid
repository structure unavailable. The secure question is where the canonical
existing target resolves, followed by an explicit root-boundary and file-type
check.

Consumer-owned acceptance remains valuable precisely because it supplies real
shapes rather than implementation assumptions. The v1 contract was secure, but
its first fixture did not represent this topology; Nautilus exposed the missing
case without requiring Mirror to absorb consumer semantics.

## Next Horizon

After the installed Nautilus rebuild advances `operational.json` and its manifest
to current Ariad truth, Nautilus can close TD-001 and resume explicit Tactical
and Strategic synthesis over a current Operational ancestor. The consumer return
remains the final gate; source-only success is insufficient.
