## Navigator Validation

```bash
uv run python ts/parity/generate_mcp_tools_golden.py            # 1. expect: no diff
cd ts && node --test "test/mcp/**/*.test.ts" && cd ..             # 2. expect: all green
scripts/mcp_two_engine_diff.sh                                    # 3. fixture DB, both engines
scripts/mcp_real_copy_probe.sh ~/.mirror-minds/<user>/memory.db  # 4. redacted copy probe
```

Step 4 copies the database into `tmp/` (never touching the original), picks the journey
with the most memories among those with at least one conversation, and runs every
deterministic tool variant through both engines — `list_journeys`, `journey_status` with
that slug, `list_conversations`, `recall_conversation` on the most recent conversation,
`detect_persona` on a fixed query, `search_memories` on the `journey`, `layer`, and `type`
filter paths, and `mirror_context` without a query. It prints per-tool SHA-256 of each
engine's payload and the line count; it never prints content.

| Observation | Pass | Fail |
|---|---|---|
| Step 1 | two `wrote` lines, `git diff` empty | golden changed on regenerate |
| Step 2 | all green | any failure |
| Step 3 | `DIFF EMPTY` | any byte difference |
| Step 4 | every tool row shows identical SHA-256 for both engines | any hash differs |
| `journey_status` payload (steps 3 and 4) | no `embedding=b'`, no `key='value'` repr | either present |
| `search_memories(query)` on the copies | zero `access_count` deltas | any delta |
