# TS6 probe — what `PreInvocation` sees on agy 1.4.7, 2026-10-25

**Branch: reachable — through the payload.** On the installed agy every hook payload
carries the turn's prompt as `lastUserInput`, so the prompt the doorman needs does not
have to be read from the transcript at all. The transcript route the plan named is
reachable too: the turn's `USER_INPUT` is already written when invocation 0 fires.

## Environment

| | |
|---|---|
| agy | 1.4.7 (`agy --version`), `~/.local/bin/agy` |
| model | the CLI default, not pinned; the probe did not record `modelName`'s value |
| date | 2026-10-25, 17:45–17:48 UTC |
| route | `agy --print` / `agy --conversation <id> --print`, headless, in a scratch workspace `/tmp/ts6-probe/ws` whose `.agents/hooks.json` carried the probe; the operator's own agy login; nothing written under `~/.gemini/config` |
| Mirror | not involved: no Mirror plugin or hook was loaded; the probe handlers are the only hooks |

The prompts were synthetic (arithmetic, "reply ok", a codeword check); nothing below is
a person's conversation. The handlers are reproduced at the end so the probe re-runs
when agy updates.

## Observations

**1. `lastUserInput` is in every payload, verbatim.** `SessionStart`, every
`PreInvocation`, and `Stop` carry it: the user's text as typed, without agy's
`<USER_REQUEST>` / `<ADDITIONAL_METADATA>` / `<USER_SETTINGS_CHANGE>` wrapping. A skill
invocation keeps its slash form, unexpanded: `/probe-skill hello there` arrived as
exactly that. The keys at `PreInvocation`: `artifactDirectoryPath`, `conversationId`,
`initialNumSteps`, `invocationNum`, `lastUserInput`, `modelName`, `transcriptPath`,
`workspacePaths`. DS7.TS2's capture on agy 1.4.2 (`pre-invocation-capture-20261018.jsonl`)
has the same keys **without** `lastUserInput`: DS12.TS3 L7 ("agy payloads carry no
prompt") was true of 1.4.2 and is not of 1.4.7. The changelog from 1.4.3 to 1.4.7 does
not mention the field; agy's bundled hook documentation
(`builtin/skills/agy-customizations/docs/hooks.md`) lists it among the common input
fields.

**2. The transcript holds the turn's prompt at invocation 0.** At every
`PreInvocation` with `invocationNum` 0, the last `USER_INPUT` in `transcriptPath` was
the current turn's, its `step_index` above the previous turn's last step, its
`<USER_REQUEST>` body equal to `lastUserInput`:

| turn | `initialNumSteps` | last `USER_INPUT` step | transcript's max step | body = `lastUserInput` |
|---|---|---|---|---|
| 1 (new conversation) | 1 | 0 | 0 | yes |
| 2 (`--conversation`) | 16 | 15 | 15 | yes |
| 3, skill turn | 19 | 18 | 18 | yes (`/probe-skill hello there`) |
| 4 | 22 | 21 | 21 | yes |

`transcriptPath` names `transcript_full.jsonl`; `transcript.jsonl` beside it held the
same steps in every read.

**3. Invocation 0 fires once per turn.** Seven turns across two conversations, one
`invocationNum` 0 each. The first turn, where the model chose to run tools, ran
invocations 0 through 6 with the same `lastUserInput`; only the first was 0.

**4. `SessionStart` fires for a new conversation, not for a resumed one.** It fired on
the first turn of each new conversation, already carrying that turn's `lastUserInput`.
Resuming with `--conversation <id>` in a new process fired no `SessionStart` (six
resumed turns).

**5. A `systemMessage` persists; an `ephemeralMessage` is dropped from context, not
from disk.** A second probe injected, at invocation 0, a `systemMessage` on turn 1
(codeword A) and an `ephemeralMessage` on turn 2 (codeword B); turn 3, in a new
process, asked for every codeword the runtime had given. The model answered A only.
The transcript (both files) recorded:

| step | type | source | content |
|---|---|---|---|
| 1 | `SYSTEM_MESSAGE` | `SYSTEM_SDK` | agy's wrapper — "The following is a `<SYSTEM_MESSAGE>` not actually sent by the user…" — then "The following system message was injected by a PreInvocation hook:" and the text |
| 4 | `EPHEMERAL_MESSAGE` | `SYSTEM_SDK` | the text, unwrapped |
| 5, 8 | `SYSTEM_MESSAGE` | `SYSTEM` | agy's own notice on each resumed process ("subagents and background tasks have been stopped due to server restart") |

So the ephemeral step is stored at rest in the conversation's transcript like the
persistent one (TS2's 2026-10-18 observation, measured again), and only the persistent
one is still before the model on a later turn, across a process restart.

## What this changes in the plan

- The prompt comes from the payload's `lastUserInput`: the transcript reader (Scope 2)
  is not needed, and neither is a high-water check at `PreInvocation` — a field read at
  invocation 0 is this turn's by construction, and invocation 0 fired once per turn.
  The hook reads no transcript at all.
- The step is a `systemMessage`, as decided: observation 5 confirms the premise.
- Restart: a resumed conversation fires no `SessionStart`, so `doorman_refresh` is not
  set on resume — and the persisted folder is still in context there (observation 5),
  so the next turn's delta stands on it.
- Open, for the Navigator: what the hook does on an agy whose payload lacks
  `lastUserInput` (1.4.2 had none).

## Left behind

## The probe handlers

`ws/.agents/hooks.json` (first probe; the second added `inject.mjs` ahead of
`probe.mjs` on `PreInvocation`):

```json
{
  "ts6-probe": {
    "SessionStart": [{ "type": "command", "command": "node /tmp/ts6-probe/probe.mjs SessionStart", "timeout": 10 }],
    "PreInvocation": [{ "type": "command", "command": "node /tmp/ts6-probe/probe.mjs PreInvocation", "timeout": 10 }],
    "Stop": [{ "type": "command", "command": "node /tmp/ts6-probe/probe.mjs Stop", "timeout": 10 }]
  }
}
```

`probe.mjs` — records the payload's keys, `invocationNum`, `initialNumSteps`,
`lastUserInput`, and the last `USER_INPUT` in `transcriptPath` and in
`transcript.jsonl` beside it; answers `{}`:

```js
import { readFileSync, appendFileSync, existsSync } from "node:fs";
import { dirname, join } from "node:path";
const event = process.argv[2];
let p = {}; try { p = JSON.parse(readFileSync(0, "utf8")); } catch {}
function lastUser(path) {
  if (!path || !existsSync(path)) return { exists: false };
  const lines = readFileSync(path, "utf8").split("\n").filter(Boolean);
  let last = null, maxStep = -1, types = {};
  for (const l of lines) { let e; try { e = JSON.parse(l); } catch { continue; }
    types[e.type] = (types[e.type] ?? 0) + 1;
    if (typeof e.step_index === "number" && e.step_index > maxStep) maxStep = e.step_index;
    if (e.type === "USER_INPUT") {
      const m = /<USER_REQUEST>\s*([\s\S]*?)\s*<\/USER_REQUEST>/.exec(e.content ?? "");
      last = { step_index: e.step_index, body: m ? m[1] : null }; } }
  return { exists: true, lines: lines.length, maxStep, types, lastUserInput: last };
}
const tp = p.transcriptPath ?? "";
appendFileSync(process.env.PROBE_OUT ?? "/tmp/ts6-probe/capture.jsonl", JSON.stringify({
  event, t: Date.now(), keys: Object.keys(p).sort(), invocationNum: p.invocationNum ?? 0,
  initialNumSteps: p.initialNumSteps, conversationId: p.conversationId,
  lastUserInputField: p.lastUserInput, transcriptFile: tp.split("/").pop(),
  transcript: lastUser(tp), sibling_transcript_jsonl: tp ? lastUser(join(dirname(tp), "transcript.jsonl")) : null,
}) + "\n");
process.stdout.write("{}\n");
```

`inject.mjs` — the persistence check:

```js
import { readFileSync } from "node:fs";
let p = {}; try { p = JSON.parse(readFileSync(0, "utf8")); } catch {}
const prompt = p.lastUserInput ?? "", inv = p.invocationNum ?? 0;
let out = {};
if (inv === 0 && prompt.startsWith("Hello, first turn"))
  out = { injectSteps: [{ systemMessage: { systemMessage: "Context note from the runtime: the first codeword is HELIOTROPE." } }] };
if (inv === 0 && prompt.startsWith("Hello, second turn"))
  out = { injectSteps: [{ ephemeralMessage: "Context note from the runtime: the second codeword is TAMARIND." }] };
process.stdout.write(JSON.stringify(out) + "\n");
```
