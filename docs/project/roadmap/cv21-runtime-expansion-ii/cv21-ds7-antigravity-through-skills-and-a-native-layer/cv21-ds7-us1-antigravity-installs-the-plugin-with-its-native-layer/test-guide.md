# Test Guide — CV21.DS7.US1

## Automated Validation

- `node --test` — the plugin-builder cases for the three generated layer
  files (committed bytes equal generated bytes, the manifest/skills
  contract extended); the wiring cases (agy detected, the Antigravity
  steps rendered, the honest counts updated); pack contents requiring the
  agy hooks file; and the full suite proving the Claude Code and Codex
  surfaces byte-identical with the layer present.
- `npx biome check .`

## E2E Decision

The live staging is the E2E: the installed agy (1.3.4) staging the real
package's plugin in a scratch `HOME`. CI has no agy binary, so the split is
DS4.US1's for Codex: generators and guards pinned in CI, the install
exercised live in the Navigator route. The route is a **committed script**
in this story package (`route.sh`), not prose (amendment h), so it re-runs
when agy updates — US4 needs the same script — and its findings land in
`evidence/` beside it (amendment f).

## Navigator Validation

1. The install stages the layer — scratch `HOME`, installed agy:
   `agy plugin install <pkg>/plugins/mirror-mind`, then list the staged
   tree. Expected observation: 25 `mm` skills plus the agy-schema hooks
   file, `mcp_config.json`, and `rules/AGENTS.md`. Pass: all staged,
   readable, in agy's shapes. Fail: a layer file missing, transformed, or
   Claude's hooks staged in place of ours.
2. `mirror init` prints the steps — on a PATH holding `agy`. Expected
   observation: an Antigravity block of at most two steps. Pass: the block,
   ≤ 2 steps. Fail: no block or more steps than Gemini CLI's two.
3. Nothing else moved — `git diff` over `plugins/mirror-mind/` beside the
   guard test. Expected observation: additions only; the Claude manifest,
   skills, and hook wrappers unchanged. Pass: byte-identical Claude/Codex
   surfaces. Fail: any file those runtimes read changed.
