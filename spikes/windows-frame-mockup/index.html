Mirror Mind para Windows

Este é um mockup funcional do futuro mirror.exe — o frame desktop que une o Pi (conversa) e o Mirror (memória e identidade) numa única experiência: instalar, entender e conversar.

O que é simulado neste mockup?
  • Simulado: as respostas do agente (roteirizadas), a validação da chave, os logins e o update.
  • Real na arquitetura: cada painel corresponde a comandos que já existem no Mirror (configure.ps1, health-check.ps1, memory identity, detect-persona, runtime update). O frame só orquestra — o core não muda.
  • O roteador de personas do “Experimente” usa a mesma lógica de keywords do detect-persona real.
>
pi /login

O que dá pra experimentar nele

  • 1º acesso completo — wizard de 6 passos: identidade → chave OpenRouter (com validação simulada e a distinção memória vs conversa explicada) → conexão de assinatura (modal simulando o pi /login) → tour de personas → primeira conversa real no terminal.
  • "Pular para o app configurado" — pra quem quiser ver direto o dia-a-dia: abas de sessão por jornada (cores!), terminal com conversa roteirizada onde as personas ativam de verdade por keyword (digite "o deploy quebrou" → ◇ engineer; "estou inseguro com o preço" → ◇ strategist; sem match → ego, sem assinatura) — a mesma lógica do detect-persona real.
  • Comandos: /help, /mm-journeys, /model, /mm-mirror funcionam no terminal.
  • ⚙ Setup com semáforos — inclusive a regra R2 encenada: o botão "Atualizar Mirror" fica desabilitado com sessões abertas; feche as abas e rode o update simulado (backup → fast-forward → migrations → warm-up), mostrando o "update sem reinstalar" como experiência.
  • ◇ Personas — glossário de modos + 12 personas com o "Experimente" interativo.
